Проект автотестирования на Cypress

Данный проект предназначен для автоматического тестирования веб-приложений с использованием Cypress. Cypress обеспечивает быструю и удобную среду для написания и выполнения тестов.

Установка
Убедитесь, что у вас установлен Node.js (рекомендуется последняя LTS-версия).
Склонируйте репозиторий:

git clone https://github.com/Ruxxl/MechtaWeb.git

Установите зависимости:

npm install
Запуск тестов
Для запуска тестов в интерфейсе:

npx cypress open
Откроется интерфейс Cypress, где вы сможете выбрать тесты для запуска.

Структура проекта

cypress/integration – директория, содержащая тестовые сценарии.
cypress/fixtures – файлы с тестовыми данными.
cypress/support – вспомогательные файлы, такие как команды и хуки.
cypress.json – файл конфигурации Cypress.

Правила написания тестов

Именование файлов: Каждый тестовый файл должен иметь понятное имя, отражающее тестируемый функционал. Например: login.spec.js, registration.spec.js.
Одна цель – один тест: Один тест должен проверять один функциональный сценарий. Это упрощает поиск ошибок.
Порядок тестов: Тесты должны быть независимыми друг от друга. Каждый из них должен начинаться с чистого состояния (например, разлогиниться, очистить данные, сбросить сессии).
Используйте Page Object: Для улучшения читаемости и повторного использования кода используйте паттерн Page Object.
Данные для тестов: Тестовые данные храните в файлах внутри директории fixtures. Не жестко кодируйте данные внутри тестов.
Логирование ошибок: В случае падения теста добавляйте понятное описание, чтобы можно было быстро локализовать проблему.
Проверка UI: Используйте селекторы, которые устойчивы к изменениям (например, атрибут data-testid).

Рекомендации

Убедитесь, что все тесты проходят перед созданием Pull Request.
Регулярно обновляйте Cypress и связанные зависимости.
Следуйте единому стилю кодирования (рекомендуется использовать ESLint с общепринятыми правилами).
